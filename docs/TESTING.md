# テスト方針

## 現在の方針: 実装優先・手動確認

機能が安定するまでは自動テストより手動確認を優先する。

### 手動確認チェックリスト

#### 基本動作
- [ ] フローティングボタンが右下に表示される
- [ ] ボタンクリックでエージェントセレクタが開く（複数エージェント時）
- [ ] エージェント選択でチャットウィンドウが開く
- [ ] メッセージを送信できる（Enter送信・Shift+Enter改行）
- [ ] 日本語IME入力が正常に動作する
- [ ] エージェントの応答がストリーミングで表示される
- [ ] ローディングアニメーション（●●●）が表示される

#### 複数エージェント
- [ ] エージェントAでチャット後、最小化してエージェントBに切り替えられる
- [ ] エージェントAに戻ると履歴が保持されている
- [ ] リロードボタンで会話をリセットできる

#### UI
- [ ] リサイズボタンでウィンドウを拡大/縮小できる
- [ ] 最小化ボタンでウィンドウを閉じフローティングボタンに戻る

#### フィードバック
- [ ] 👍クリックでカテゴリpill + textarea + 送信パネルが開く
- [ ] 👎クリックでカテゴリpill + textarea + 免責文 + 送信パネルが開く
- [ ] カテゴリpillを複数選択できる
- [ ] カテゴリ未選択・テキスト未入力でも送信できる
- [ ] キャンセルボタンでパネルが閉じる（ボタンは未評価状態に戻る）
- [ ] 送信後にDB2エントリが作成される
- [ ] DB2に `question`（直前のユーザー発言）が記録される
- [ ] DB2に `answer`（エージェント回答）が記録される
- [ ] DB2に `isPositive`（1 or 0）が正しく記録される
- [ ] DB2に `categories`（カンマ区切り）が記録される
- [ ] DB2にGaroonユーザー情報（name, garoonId等）が記録される
- [ ] 複数エージェントそれぞれでフィードバックが正しい `agentId` で記録される

#### ブラウザ確認（最低限）
- [ ] Chrome（最新版）
- [ ] Edge（最新版）

## 将来: 自動テスト（実装が安定したら）

### ユニットテスト対象（Jest）
- `Config.js` - 設定値検証
- `HttpClient.js` - HTTPリクエスト・ストリーミング
- `ChatManager.js` - スレッド管理・メッセージパース
- `AuthManager.js` - 匿名UUID生成

### E2Eテスト対象（Playwright）
- 基本チャットフロー
- 複数エージェント切り替え
- フィードバック送信

### セットアップ
```bash
npm install --save-dev jest @playwright/test
npm test           # ユニットテスト
npm run test:e2e   # E2Eテスト
```
